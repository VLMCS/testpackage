# Claude Code Instructions

Development Rules

- Work ONLY on a dedicated feature branch.
- Never modify main directly.
- Additive changes only.
- Preserve existing functionality.
- Avoid destructive schema changes.
- Prefer optional Firestore fields or new collections.

Testing

- Verify existing features still work.
- New features must be isolated until approved.

Goal

Transform the application into an AI Finance Planner without regressing the current Budget Tracker.
