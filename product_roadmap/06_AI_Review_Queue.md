# AI Review Queue

Purpose

Every AI-generated transaction must be reviewed before being committed.

Sources

- Voice
- AI Chat
- Notifications
- OCR (future)

Fields

- Confidence Score
- Amount
- Wallet
- Merchant
- Category
- Transaction Type

High confidence

Accept
Edit

Medium confidence

Ask user for clarification.

Benefits

- Prevent incorrect financial records.
- Safe AI automation.
- Maintain user trust.
