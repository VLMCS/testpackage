# Project Vision

## Mission
Transform the existing Budget Tracker into an AI-assisted Finance Planner that helps users make better financial decisions instead of simply recording historical transactions.

## Core Philosophy

Old:
Transactions → Reports

New:
Finance Plans → Wallet Allocations → Transactions → Reports → AI Insights

The application should feel like an AI Financial Coach.

## Non-Negotiable Rules

- Additive development only.
- Never break existing functionality.
- Maintain backward compatibility.
- Develop only on a dedicated feature branch.
- Preserve Firestore schema whenever possible by extending it rather than replacing it.
